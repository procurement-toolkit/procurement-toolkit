HS Code 조회 & 관세율 확인 가이드

HS Code를 잘못 찾으면 관세 과오납, 통관 지연, 심하면 추징까지 이어질 수 있습니다. 저희가 직접 코드나 세율을 알려드리는 대신, 각국 관세당국의 공식 조회 도구로 바로 연결해드리고, 정확하게 검색하는 요령을 정리했습니다.

품목분류공식 데이터 연결관세율 조회
⚠ HS Code 분류는 전문 분류업체의 AI 도구조차 정확도가 70~80%대에 머무를 만큼 까다로운 영역입니다. 이 페이지는 직접 코드를 판정해드리지 않고, 공식 관세당국 데이터로 바로 연결해드립니다. 고액 거래나 중요한 판정은 반드시 관세사와 상담하세요.

HS Code, 이렇게 구성됩니다

HS Code는 세계관세기구(WCO)가 정한 앞 6자리 국제 공통 코드에, 각 나라가 자국 통계·관세 목적으로 자릿수를 추가하는 구조입니다.

예: 8471.30 (노트북 컴퓨터, 앞 6자리는 전 세계 공통)
→ 미국은 여기에 4자리를 더해 10자리 HTS 코드로 확장
→ EU는 8자리 CN(Combined Nomenclature) 코드 사용
→ 한국은 10자리 HSK(HS of Korea) 코드 사용

즉 앞 6자리만 맞으면 국제적으로 같은 대분류지만, 정확한 세율 적용을 위해서는 수입국 기준의 전체 자릿수까지 확인해야 합니다.

정확하게 검색하는 3단계

제품명 + 재질 + 용도로 검색

단순히 "가방"이 아니라 "가죽 핸드백" 또는 "폴리에스터 백팩"처럼 재질과 용도를 함께 넣으면 검색 범위가 좁혀집니다.

국내사례 검색으로 교차 확인

유니패스 CLIP의 "국내사례" 메뉴에서 비슷한 물품이 실제로 어떤 코드로 신고됐는지 과거 사례를 확인하면 정확도가 올라갑니다.

애매하면 관세평가분류원에 사전심사 요청

애매한 품목은 관세청 관세평가분류원에 품목분류 사전심사를 신청하면 공식적으로 확정된 코드를 받을 수 있습니다 (수수료 있음, 처리에 시간 소요).

자주 하는 실수

용도에 따른 분류 오류

같은 "유리컵"이라도 장식용인지 주방용인지에 따라 코드가 달라질 수 있습니다.

재질 판단 착오

가죽 가방인 줄 알았는데 합성피혁이었던 경우처럼, 재질 하나 차이로 관세율이 달라져 추징 대상이 될 수 있습니다.

FTA 세번변경기준 미확인

FTA 특혜관세를 받으려면 HS Code가 실제로 바뀔 만큼의 가공이 이루어졌는지 확인해야 하는데, 이를 안 하고 협정세율을 적용했다가 사후 심사에서 적발되는 경우가 많습니다.

자주 묻는 질문

HS Code를 잘못 신고하면 어떻게 되나요?

관세 과오납(더 내거나 덜 내거나), 통관 지연, 심한 경우 세관 사후 심사에서 적발되어 가산세와 함께 추징될 수 있습니다. 애매한 품목은 사전심사를 받는 것이 안전합니다.

수출용 코드와 수입용 코드가 다른가요?

네, 나라에 따라 다를 수 있습니다. 예를 들어 미국은 수입 시 10자리 HTS 코드, 수출 시에는 별도의 Schedule B 코드(역시 10자리)를 사용하며, 앞 6자리는 서로 같습니다.

같은 HS Code라도 나라마다 관세율이 다른가요?

네, HS Code 앞 6자리가 같아도 실제 적용되는 관세율은 수입국, 원산지, FTA 체결 여부에 따라 크게 달라질 수 있습니다. 코드 확인 후 반드시 수입국 기준 관세율표를 따로 확인해야 합니다.

HS Code 완벽 가이드: 구조, 6자리와 10자리 차이, 품목분류 방법, 관세율 확인

HS Code(품목분류번호)는 수출입하는 모든 물품에 붙는 국제 공통 분류 번호이고, 관세율, 수입 요건, FTA 적용 여부가 이 번호에서 결정됩니다. 번호를 잘못 분류하면 관세 추징이나 통관 지연으로 이어질 수 있어서 수입 실무에서 가장 먼저 확인하는 항목입니다. 이 글은 HS Code의 구조, 한국의 10자리 체계, 품목분류의 기본 원칙, 관세율을 확인하는 순서를 정리했습니다.

HS Code란 무엇인가

HS(Harmonized System, 통합상품명 및 부호체계)는 세계관세기구(WCO)가 관리하는 국제 상품 분류 체계로 1988년에 시행되었고, 200개가 넘는 국가와 지역이 관세율 적용과 무역 통계에 사용합니다. 분류 체계는 5년 안팎의 주기로 개정되며 현재는 2022년판이 시행 중이고, 다음 개정판은 2027년 시행이 예정되어 있습니다.

숫자는 어떻게 구성되어 있나

HS 번호의 앞 6자리는 모든 나라가 공통으로 쓰고, 7자리부터는 나라마다 세분화합니다.

자리명칭예시 의미
앞 2자리류(Chapter)큰 분류. 1~97류(77류는 비어 있음)
앞 4자리호(Heading)류 안의 품목군
앞 6자리소호(Subheading)국제 공통 최소 분류
7~10자리국가별 세분류한국은 HSK 10자리, 미국 HTS 10자리, EU는 CN 8자리

한국의 수출입 신고에는 10자리 HSK 번호를 쓰고, 상대국과 거래할 때는 6자리까지만 같을 수 있다는 점을 알아 두어야 합니다. 같은 제품이라도 나라에 따라 7자리 이후의 번호와 관세율이 다릅니다.

품목분류의 기본 원칙

HS는 "해석에 관한 통칙" 6개 조항으로 분류 기준을 정합니다. 실무에서는 아래 순서로 생각하면 도움이 됩니다.

  1. 제품의 재질, 구성, 용도, 작동 원리, 포장 상태를 확인합니다.
  2. 해당할 만한 류(Chapter)를 찾고, 부(Section)와 류의 주(Note)에서 제외되거나 포함되는 품목을 확인합니다.
  3. 호(Heading) 용어와 주에 따라 호를 정합니다(통칙 1).
  4. 둘 이상의 호에 해당하는 것처럼 보이면 더 구체적으로 표현된 호를 우선하고, 세트나 혼합물은 주된 특성에 따라 분류합니다(통칙 2, 3).
  5. 소호는 같은 호 안에서 같은 원칙으로 정합니다(통칙 6).
  6. 한국 10자리는 관세·통계 부호표에서 마지막으로 확정합니다.

분류에서 자주 틀리는 제품 유형

  • 세트 상품: 구성품을 따로 분류할지, 하나의 세트로 분류할지는 소매용 세트 요건에 따라 달라집니다.
  • 부품과 완제품: 기계류 부분품은 부(Section)와 류의 주에 별도 규정이 있는 경우가 많습니다.
  • 소재 혼합 제품: 섬유, 플라스틱, 금속이 섞인 제품은 주된 소재나 본질적인 특성으로 분류합니다.
  • 식품과 건강기능식품: 원료 함량, 제형, 용도에 따라 류가 달라질 수 있습니다.
  • 전자기기: 기능이 여러 개인 제품은 주된 기능을 기준으로 판단합니다.

관세율은 어떻게 확인하나

  1. HS 번호를 정하면 관세청 관세법령정보포털(CLIP)이나 UNI-PASS에서 해당 번호의 관세율을 조회합니다.
  2. 기본관세율, 잠정관세율, 협정(FTA)관세율, 할당관세 등 적용 가능한 세율을 비교합니다.
  3. FTA를 적용하려면 원산지 결정 기준을 충족하는지와 원산지증명서가 필요합니다.
  4. 수입 요건(KC, 식품 검역, 전파 인증 등)이 걸려 있는 품목인지도 같은 번호로 확인합니다.

FTA 세율 적용은 원산지증명서(FTA) 가이드와 원산지 규정(RVC) 계산기에서 이어서 확인하세요.

분류가 불확실할 때 쓸 수 있는 제도

한국 관세청은 수입하기 전에 품목분류를 미리 확인받을 수 있는 품목분류 사전심사 제도를 운영합니다. 분류에 따라 관세율이 크게 달라지거나 금액이 큰 거래라면, 수입 전에 사전심사를 신청해 결과를 받아 두면 통관 후 분류 분쟁 위험을 줄일 수 있습니다. 구체적인 신청 방법과 처리 기간은 관세청 안내를 확인하세요.

HS Code 확인 실무 체크리스트

  • 제품의 정확한 명칭, 재질, 성분 비율, 용도, 작동 방식을 정리했는가
  • 제조사 사양서나 성분표를 확보했는가
  • 공급사가 제시한 HS 번호를 그대로 믿지 않고 한국 기준으로 다시 확인했는가
  • 비슷한 품목의 이전 수입 신고 사례를 확인했는가
  • 관세율과 함께 수입 요건과 FTA 적용 가능성을 확인했는가
