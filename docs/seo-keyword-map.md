1. 검색어별 전용 랜딩 페이지 (제목·H1·첫 문단에 검색어)
2. 네이버 서치어드바이저: 사이트맵·RSS(rss.xml) 제출, 수집 요청 (소유자 작업)

4. Event 구조화 데이터 (전시회 상세, 적용됨), FAQPage (계산기, 적용됨)
5. 외부 링크: 지식iN 답변, 블로그, 커뮤니티, GitHub, 디렉터리 (소유자 작업, 초안은 Claude가 작성)
